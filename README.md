# Telegram Reminder Bot

A simple Telegram bot written in Python using the **python-telegram-bot** library.

## Features

* Welcome users with `/start'
* Custom keyboard buttons
* Create reminders
* Send reminder messages at a specified time
* Easy to understand and extend

## Requirements

* Python 3.10+
* python-telegram-bot

## Installation

Clone the repository:

```bash
git clone <repository-url>
cd telegram_bot
```

Create a virtual environment:

```bash
python3 -m venv .venv
```

Activate it:

```bash
source .venv/bin/activate
```

## Run

```bash
python3 Reminder_bot.py
```
